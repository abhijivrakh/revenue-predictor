
# Revenue Intelligence Predictor

This is an end-to-end machine learning web application that predicts business revenue based on marketing spend and business signals.

## Problem Statement

Businesses spend money across different marketing channels such as TV ads, social media, Google ads, email marketing, influencer campaigns, and discounts. This application predicts expected revenue based on these inputs and gives a simple business recommendation.

## Tech Stack

- Python
- Pandas
- Scikit-learn
- XGBoost Regressor
- Streamlit
- Plotly
- Joblib

## Model

The project uses an XGBoost Regressor with preprocessing pipeline and hyperparameter tuning.

## Features

- Interactive revenue prediction
- Business-level recommendation
- Model performance metrics
- Marketing spend visualization
- Batch CSV prediction
- Downloadable prediction output

## Target Column

Revenue

## Deployment

Deployed using Streamlit Cloud.
